# NEON STRIKE // Ashes of Orbit — Power Build Edition

A self-contained, browser-playable top-down sci-fi action campaign. No installation, internet connection, API key, or game engine setup required.

🎮 **Play Online**: [Play Neon Strike](https://tiraxmunna.github.io/Neon/) (when GitHub Pages is enabled)

---

## Features
- **8 Story Missions & Arenas**: Face runners, gunners, tanks, furnace hazards, and command-class bosses (Commander Sentinel, Heavy Platform Titan, and Final AI Oblivion).
- **Power Build System**: Draft 1 of 3 permanent upgrades before every mission. Upgrades stack up to 8 powers across the campaign.
- **Responsive Controls**: Smooth keyboard + mouse controls and mobile touchscreen virtual joystick + action buttons.
- **Offline & Local Progress**: Campaign progress, unlocked sectors, power builds, and high scores save automatically in your browser's local storage.
- **Dynamic Action Combat**: Phase Dash with invulnerability frames, EMP Surge burst at 100% charge, combo streak multipliers, and clutch health recovery.

---

## Controls

### Keyboard & Mouse
| Action | Key / Input |
|---|---|
| **Move** | `W` `A` `S` `D` or `Arrow Keys` |
| **Aim** | `Mouse Cursor` |
| **Fire** | `Left Click` or `Spacebar` |
| **Phase Dash** | `Shift` |
| **EMP Surge** | `E` (at 100% charge) |
| **Pause / Resume** | `P` or `Esc` |

### Touchscreen
- Use the virtual joystick on the lower-left to move.
- `FIRE` button on the lower-right auto-aims and fires at the nearest enemy.
- `PHASE DASH` and `EMP` buttons for evasive maneuvers and full-screen discharge.

## Level Missions
1. **Sector 01 — Signal Breach**: Introductory combat training.
2. **Sector 02 — Scrapline**: Salvage gold power cores from scrap patrols.
3. **Sector 03 — The Sentinel**: Eliminate escort guards and defeat Commander Sentinel.
4. **Sector 04 — Black Foundry**: Evade charging furnace heat lanes and survive the lockdown.
5. **Sector 05 — Ghost Protocol**: Infiltrate and destroy three secure data relays.
6. **Sector 06 — Titan Protocol**: Duel the heavy armored Titan platform.
7. **Sector 07 — Core Breach**: Destroy reactor locks while dodging core shock pulses.
8. **Sector 08 — Last Firewall**: The final showdown against the central AI network Oblivion.

---

## How to Play Locally
Simply clone or download this repository and double-click `index.html` in Chrome, Edge, or any modern web browser.
