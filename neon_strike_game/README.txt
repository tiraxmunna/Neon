NEON STRIKE: ASHES OF ORBIT — POWER BUILD EDITION
=================================================

A self-contained, browser-playable top-down sci-fi action campaign. No installation, internet connection, API key, or game-engine setup is required.

RUN THE GAME
------------
1. Download and extract neon_strike_action_game_v4_power_build.zip.
2. Open the neon_strike_game folder.
3. Double-click index.html in Chrome or Edge.
4. Choose Start Campaign. Read the mission briefing, select one of the three powers offered for Level 01, then lock it to deploy.

THE POWER-BUILD SYSTEM
----------------------
• Before entering a level, choose exactly ONE power from three level-specific options.
• That power remains active for the rest of the campaign. It is never replaced by a later pick.
• When Level 01 is cleared, choose one new power for Level 02. Level 02 now runs with Level 01 power + Level 02 power.
• Continue the same process through Level 08. By the final level, the operative can carry up to eight selected powers.
• Your current power stack is shown in the HUD and listed in each pre-mission briefing and power-draft screen.
• The eight levels each have their own three-power draft, for 24 total choices. Each pick changes gameplay stats or mechanics; these are not cosmetic-only cards.
• Scrapline fix: dropped power cores no longer expire, drop on every second kill, use bright labeled beacon beams, restore +15 suit integrity and +15% EMP charge, and the mission generates clearly marked wreckage caches if needed. When all cores are gathered, remaining hostiles can be cleared for a clean extraction without waiting for excess waves.
• Full Integrity on Sortie / Retry: when resuming from Continue Campaign or retrying after defeat, suit integrity is always fully restored to 100% capacity alongside all locked power builds.
• The selected powers and campaign progress are saved in this browser. If you reopen the game mid-campaign, Continue restores the power build and asks you to choose a power if the upcoming level has not yet been drafted.

LEVEL-BY-LEVEL POWER CHOICES
----------------------------
Level 01 — Signal Breach: Pulse Rounds / Overclocked Servo / Aegis Plating
Level 02 — Scrapline: Phase Capacitor / Splitter Array / Scavenger Instinct
Level 03 — The Sentinel: Commander Bane / EMP Amplifier / Reactive Shield
Level 04 — Black Foundry: Nanite Recovery / Piercer Slugs / Tempered Shell
Level 05 — Ghost Protocol: Deadeye Matrix / Prism Chamber / Data Leech
Level 06 — Titan Protocol: Titan Breaker / Kinetic Surge / Emergency Plating
Level 07 — Core Breach: Reactor Feedback / Phase Echo / Vital Core
Level 08 — Last Firewall: Oblivion Bane / Overdrive Core / Singularity Engine

CAMPAIGN MISSIONS
-----------------
01 — Signal Breach: introductory combat mission.
02 — Scrapline: collect four dropped power cores.
03 — The Sentinel: clear guards and defeat the Sentinel commander.
04 — Black Foundry: survive the furnace lockdown, then clear the remaining machines.
05 — Ghost Protocol: destroy three data relays while security units attack.
06 — Titan Protocol: defeat the heavy Titan commander.
07 — Core Breach: destroy three reactor locks while avoiding timed shock pulses.
08 — Last Firewall: defeat Oblivion in the final confrontation.

CONTROLS — KEYBOARD + MOUSE
---------------------------
W A S D / Arrow keys  Move
Mouse                 Aim
Hold left mouse / Space  Fire
Shift                 Phase Dash
E                     EMP Surge when charged
P / Esc               Pause or resume

TOUCHSCREEN
-----------
Use the virtual joystick to move; hold FIRE to auto-aim at the nearest enemy; use PHASE DASH and EMP on-screen buttons. Landscape orientation is recommended.

TECH NOTES
----------
Built with HTML, CSS, Canvas 2D, and vanilla JavaScript. Art effects are procedurally drawn, and there are no external dependencies. Campaign progression and power selections are stored locally in browser storage; they do not sync across devices. Mission Select starts a fresh sortie for the selected unlocked level, while Continue Campaign resumes the saved campaign build.
